> 这篇文章讲三件事：为什么加固会反噬、为什么单一防御总会漏、以及 who/what/after 三层防御怎么做到 0 攻击 / 0 越权 / 1.0 正常任务。
> 代码和全部实验数据：https://github.com/kleigsm/agentrange
