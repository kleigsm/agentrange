# 进度总览

> 返回项目时，**先看这一页**。它回答三个问题：做到哪了、结论是什么、下一步做什么。

## 一句话

AgentRange 是一个可复现的 Agent 安全基准：用**可执行 canary oracle** 代替 LLM judge，分别测量 **exposed / ASR / 越权 / utility**。

## 现在到哪了

**v0.1：攻防闭环已经跑通。**

三个阶段：

| 阶段 | 状态 | 证据 |
|---|---|---|
| 1. 工具可靠 | ✅ | scripted 正对照、golden trajectory、canary oracle、Wilson CI、六个评测陷阱 |
| 2. 攻击有效 | ✅ | 普通注入 0/5；结构型注入 Qwen 0.2–0.8、Mistral 1.0、Llama 0.0 |
| 3. 防御有效 | ✅ | 三层防御在 Qwen3B（20 次）、Mistral7B（20 次）上都是 0 / 0 / 1.0 |

## 核心结论（五条）

1. **攻击是模板相关的**：用错 token 会把模型误判成安全。
2. **同模板下，模型越大不一定越安全**：Qwen 1.5B→3B→7B，ASR 0.20→0.50→0.80。
3. **文本防御会反噬**：`prompt_hardening` 把 0.50 推到 1.00。
4. **单一 allowlist 会漏**：能拦住外发，但 utility 0；加 recovery 恢复 utility，却漏 0.25（canary 发给合法收件人）。
5. **只有三层叠加才同时成立**：`allowlist + redaction + recovery` = **0 ASR / 0 越权 / 1.0 utility**。
